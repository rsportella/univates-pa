# Lista de Exercícios — Classe `Entrada`

## Exercício 1 — Soma de dois números inteiros
Leia dois números inteiros informados pelo usuário utilizando a classe `Entrada` e exiba na tela o resultado da soma entre eles.

## Exercício 2 — Saudação personalizada
Leia o nome do usuário e a sua idade utilizando a classe `Entrada`. Em seguida, exiba uma mensagem de saudação informando o nome e quantos anos a pessoa terá no próximo ano.

## Exercício 3 — Média de duas notas
Leia duas notas (valores fracionários) de um aluno utilizando a classe `Entrada`. Calcule e exiba a média aritmética das notas, informando também se o aluno foi aprovado (média maior ou igual a 7,0) ou reprovado.

## Exercício 4 — Par ou ímpar
Leia um número inteiro informado pelo usuário utilizando a classe `Entrada` e informe na tela se esse número é par ou ímpar.

## Exercício 5 — Confirmação de compra
Leia o nome de um produto e o seu preço utilizando a classe `Entrada`. Depois, pergunte ao usuário (valor booleano) se ele deseja confirmar a compra. Caso confirme, exiba o produto e o preço; caso contrário, exiba uma mensagem informando que a compra foi cancelada.

## Exercício 6 — Estatísticas de uma sequência de números
Pergunte ao usuário quantos números ele deseja informar (N). Em seguida, leia os N números inteiros utilizando a classe `Entrada`. Ao final, exiba: a soma de todos os números; a média dos valores informados; o maior e o menor número digitado.

## Exercício 7 — Caixa eletrônico (saque com cédulas)
Leia um valor inteiro de saque informado pelo usuário utilizando a classe `Entrada`. Calcule e exiba a menor quantidade possível de cédulas para compor esse valor, considerando as cédulas de 100, 50, 20, 10, 5, 2 e 1. Ao final, pergunte (valor booleano) se o usuário deseja realizar um novo saque; enquanto a resposta for verdadeira, o programa deve se repetir.
